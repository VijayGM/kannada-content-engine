# n8n Workflow JSON (reference only)

The scripts in `scripts/` are what actually run in production (see the main
README's "Editing workflows in n8n" section for why). This folder is for
exported n8n workflow JSON if you build/prefer to design the logic visually
in n8n's editor before translating it to a script — useful for prototyping
prompt chains or visualizing the pipeline, not required for the pipeline to run.

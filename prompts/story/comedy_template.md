# Prompt template: Comedy category (starting point — edit freely)

Used by `scripts/plan_and_script.py`'s `generate_concepts()` and
`generate_script()` functions as inline prompts. This file exists so you can
iterate on wording without touching code — copy refined wording back into
the script once you're happy with it, or refactor the script to read these
files directly if you want faster iteration.

Tone: fast, punchy, situational — misunderstandings, exaggerated reactions,
everyday domestic or workplace friction. Natural Kannada-English code-mixing
where a real person would actually mix (frustration, slang, tech/office terms).
Avoid literal-translation phrasing.
